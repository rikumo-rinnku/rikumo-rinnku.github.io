原神剧情爬虫笔记07：组织模块（organization.py）

发表于2026-08-31|更新于2026-08-31|开发记录
|总字数:1.7k|阅读时长:6分钟|浏览量:

本文档记录了《原神》观测枢组织爬虫模块的设计思路、API 分析、数据结构解析和实现细节，适用于项目维护和后续扩展。

一、模块概述

模块名称：organization.py
功能：从米哈游观测枢 Wiki 爬取所有组织的详细信息，包括：

  • 组织简介（good_desc 模块）
  • 重要事件（timeline_base_info 模块）
  • 成员列表、下属机构、历史逸闻等（collapse_panel 模块）
  • 额外属性（如“魔神战争”、“尘世七执政”等）

输出：每个组织保存为一个 .txt 文本文件，存放在 data/cleaned/organization/ 目录下。

增量策略：

  • 使用 crawled.json 记录已爬取的组织 ID。
  • 每次运行先检查 ID 是否已记录，若已记录则跳过，避免重复请求。
  • 若官方更新了内容，需手动从 crawled.json 中删除对应 ID，重新运行以更新。

组件 用途

requests + tenacity HTTP 请求与自动重试

logging 日志记录（文件 + 控制台）
项目内部模块 client, parser, config_loader, storage

3.2 组织详情 API

  • URL: https://act-api-takumi-static.mihoyo.com/hoyowiki/genshin/wapi/entry_page
  • 参数: app_sn=ys_obc, entry_page_id={组织ID}, lang=zh-cn
  • 核心字段:
    • page.modules[]：所有内容模块。
    • modules[].components[].data：实际数据（JSON 字符串）。
    • 关键模块：
      • good_desc：简介（含 rich_text 和 attr 字段）。
      • timeline_base_info：重要事件（时间线）。
      • collapse_panel：可折叠面板，包含成员列表、下属组织、逸闻等。

4.3 引用替换（核心难点）

观测枢的「详情」脚注以嵌套 HTML 的形式存储在 data-name 属性中，例如：

处理步骤：

  1. 正则匹配所有 data-type="详情" 的 <span>。
  2. 提取 data-name 属性值，使用 html.unescape 解码 HTML 实体。
  3. 用 BeautifulSoup 解析解码后的 HTML。
  4. 遍历所有 <p> 标签，提取每个 custom-entry-wrapper 的完整显示文本（<a> 文本 + 后续文本节点，如“·神之眼”）。
  5. 将所有名称合并为一个 (相关内容：xxx yyy zzz) 的字符串，替换原 <span>。

4.4 跳过空模块

collapse_panel 中可能包含空内容或仅包含图片的占位模块，通过 is_collapse_panel_empty 函数判断（去除标签后文本长度 < 10 字符视为空）。

每个组织保存为一个 .txt 文件，文件名使用组织名称（非法字符替换为 _）。

十、注意事项

  1. 引用处理的特殊性：组织模块的引用需要从 data-name 属性中提取，这是与角色、武器等模块不同的地方，因此引用处理逻辑放在 organization.py 内部，而非全局 parser.py。
  2. attr 字段：good_desc 中除 rich_text 外，还可能包含 attr 键值对，需要一并提取并追加到简介末尾。
  3. 空模块过滤：collapse_panel 中可能包含空内容，通过 is_collapse_panel_empty 过滤，避免生成空白段落。
  4. 网络超时：如遇 SSL 超时，可检查网络连接或增加 timeout 参数。
  5. 文件名清洗：组织名称可能包含特殊字符，使用 safe_filename 替换为下划线。

十一、后续优化方向

  1. 支持命令行参数：通过 argparse 控制爬取范围和模式。
  2. 内容变更检测：通过哈希值检测内容变化，替代手动删除 ID。
  3. 多线程并发：使用 ThreadPoolExecutor 加速（需控制并发数）。
  4. 提取更细粒度的成员列表：如果未来需要，可以从 collapse_panel 中解析出更结构化的成员数据。
