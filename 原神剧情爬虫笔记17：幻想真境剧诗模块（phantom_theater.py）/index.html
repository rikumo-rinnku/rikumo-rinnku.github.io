原神剧情爬虫笔记17：幻想真境剧诗模块（phantom_theater.py）

发表于2026-08-31|更新于2026-08-31|原神剧情爬虫笔记
|总字数:1.7k|阅读时长:5分钟|浏览量:

本文档记录了《原神》观测枢幻想真境剧诗（月谕圣牌）爬虫模块的设计思路、API 分析、数据结构解析和实现细节，适用于项目维护和后续扩展。

一、模块概述

模块名称：phantom_theater.py
功能：从米哈游观测枢 Wiki 爬取所有“幻想真境剧诗”玩法中的“月谕圣牌”描述文本，包括：

  • 圣牌名称（如「月谕圣牌·一·魔法师」）
  • 圣牌描述/诗歌（每张牌包含一段诗意的文字，具有 Lore/文化价值）

输出：每张圣牌保存为一个 .txt 文本文件，存放在 data/cleaned/phantom_theater/ 目录下。

增量策略：

  • 使用 crawled.json 记录已爬取的圣牌 ID。
  • 每次运行先检查 ID 是否已记录，若已记录则跳过，避免重复请求。

二、技术栈

组件 用途
Python 3.12+ 运行环境
requests + tenacity HTTP 请求与自动重试
json 解析 API 响应
logging 日志记录（文件 + 控制台）
项目内部模块 client, parser, config_loader, storage

三、API 分析

3.1 圣牌列表 API

  • URL: https://act-api-takumi-static.mihoyo.com/common/blackboard/ys_obc/v1/home/content/list
  • 参数: app_sn=ys_obc, channel_id=249（幻想真境剧诗频道）
  • 响应结构:

3.2 圣牌详情 API

  • URL: https://act-api-takumi-static.mihoyo.com/hoyowiki/genshin/wapi/entry_page
  • 参数: app_sn=ys_obc, entry_page_id={圣牌ID}, lang=zh-cn
  • 核心字段:
    • page.modules[].components[].data：包含 multi_table 组件。
    • tables[].row[][1]：第二列包含圣牌的标题和诗歌文本。

3.3 特殊说明

  • 幻想真境剧诗频道的列表数据中，包含多种类型的条目（月谕圣牌、演出事件、演出奖励、演出规则等）。
  • 本模块只保留“类别/月谕圣牌”的条目，其他类型全部跳过。
  • 圣牌的描述文本以诗歌/塔罗牌释义的形式呈现，具有 Lore 价值，是剧情文本的重要补充。

提取逻辑：

  1. 遍历 modules，查找 multi_table 组件。
  2. 遍历 tables，取每个 row 的**第二列（索引 1）**的 HTML 文本。
  3. 使用 clean_html_to_text 清洗 HTML，保留诗歌格式。
  4. 如果一行只有一列（可能某些牌结构不同），则取第一列（索引 0）。

输出格式：每段描述用空行分隔，保留原诗的排版风格。

4.3 跳过模块

演出奖励 ❌ 跳过 纯数值列表
演出规则 ❌ 跳过 纯机制说明
本期规则 ❌ 跳过 纯机制说明

十、注意事项

  1. 仅保留圣牌：幻想真境剧诗频道下有多种条目类型（演出事件、演出奖励等），本模块仅爬取“类别/月谕圣牌”的条目。
  2. 无描述则跳过：若某张圣牌没有描述文本，该圣牌将被跳过，不生成文件。
  3. 诗歌格式保留：clean_html_to_text 会保留原诗的换行和排版格式，确保诗歌的可读性。
  4. 文件名清洗：圣牌名称可能包含特殊字符（如 ·、・），使用 safe_filename 替换为下划线。
  5. 空内容过滤：若圣牌详情页无任何可提取文本，该圣牌将被跳过，不生成文件。

十一、与已有模块的对比

特性 圣牌模块（phantom_theater.py） NPC 模块（npc.py） 动物模块（animal.py）
频道 ID 249 20 49
分类标签 仅“类别” 地区、类型、牌手挑战等 动物类型、是否可捕获
列表结构 扁平列表，需过滤 扁平列表 扁平列表
核心内容 诗歌/描述文本 NPC 信息、对话、商品 背景故事
特有组件 multi_table（单行双列） npc_base_info、collapse_panel good_desc
输出粒度 每张圣牌一个文件 每个 NPC 一个文件 每个动物一个文件

十二、后续优化方向

  1. 自动识别所有圣牌：当前通过 ext 中的“类别/月谕圣牌”过滤，未来如果新增“塔罗牌”等其他类别，可扩展过滤条件。
  2. 多语言支持：圣牌描述目前仅中文，未来可扩展为多语言版本。
  3. 分页支持：当前频道下条目较少（~30），无需分页。如果未来扩展，可参考其他模块的分页逻辑。
